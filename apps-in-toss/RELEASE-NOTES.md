## 콘솔 검토 제출용 (최초 출시)

콘솔 "검토 전 입력" 화면에 그대로 넣는 값. 확정본은 `apps-in-toss.config.json`의
`reviewReleaseNote` / `mainFeatures` 참고.

### 출시 노트 (주요 기능 소개)

> 성향 테스트 허브는 다양한 성향·심리 테스트를 한 곳에 모은 미니앱이에요.
> (1) 홈에서 '오늘의 성향 테스트', 랜덤 시작, 전체 테스트 목록 중 원하는 테스트를 골라요.
> (2) 몇 개의 객관식 질문에 답하면 결과 유형을 계산해요.
> (3) 결과 화면에서 유형 요약과 강점·주의할 점, 축 점수, '나와 같은 성향'을 가진 사람의 희소도를 보여주고 친구에게 공유할 수 있어요.
> 별도 로그인 없이 바로 이용할 수 있고, 테스트 콘텐츠는 웹에서 받아와 새 테스트가 계속 추가돼요.
> 결과 화면 진입 시 전면 광고가 1회 노출돼요.

### 주요 기능 (최대 3개)

앱은 단일 화면(라우트 `/`)이라 모든 이동 URL은 홈으로, screenName은 비웁니다.

| # | 한국어 기능 이름 | 영어 기능 이름 | 이동 URL | screenName |
|---|---|---|---|---|
| 1 | 성향 테스트 하기 | Take a Trait Test | `intoss://trait-test-hub/` | (비움) |
| 2 | 오늘의 성향 테스트 | Today's Trait Test | `intoss://trait-test-hub/` | (비움) |
| 3 | 전체 테스트 둘러보기 | Browse All Tests | `intoss://trait-test-hub/` | (비움) |

> 참고: `apps-in-toss.config.json`의 `featureUrls`에 있는 `.../test`, `.../result`는
> 현재 라우터에 없는 경로라 딥링크가 홈으로 폴백됩니다. 실제 딥링크가 필요하면
> 라우트를 추가해야 합니다.

### 이번 배포에 담긴 것 (내부 변경 요약)

- SDK 트랙 전환: Granite RN(`@apps-in-toss/framework@^2.10.10`) 제거, `@apps-in-toss/web-framework@^3.x` + Vite + React 18로 전환.
- product-core 통합: esbuild 번들링(`bundle:core`, `src/vendor/`) 제거. 워크스페이스 패키지(`@seorilabs/trait-test-core`)의 `exports`/`types` 필드를 추가해 Vite가 직접 resolve.
- 홈 카테고리화: `Manifest.filters.categories` 기반 칩 + 카테고리별 섹션 묶기. 칩 선택 상태는 Storage에 저장.
- 결과 화면 개선: 같은 카테고리의 다른 published 테스트 1~3개를 "비슷한 테스트 더 보기" 카드로 노출.
- 콘솔 작업: `https://<appName>.apps.tossmini.com`, `https://<appName>.private-apps.tossmini.com` origin을 콘솔 origin 허용 목록과 Firestore API 키 HTTP 리퍼러에 추가 필요.
